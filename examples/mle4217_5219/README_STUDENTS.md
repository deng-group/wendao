# MLE4217/5219 AI Learning Agent

This AI assistant is for MLE4217/5219 course learning only.

## What You Can Ask

You can ask about:

- Concepts covered in the slides.
- Connections between course topics.
- Notebook or coding examples used in the course.
- Course logistics, such as assignments, quizzes, exams, grading, and deadlines.

Example questions:

- `What is convex hull?`
- `How does convex hull relate to phase stability?`
- `How is Materials Project data used to train MACE potentials?`

## Answer Policy

The assistant answers strictly based on the course slides and course materials. It will not answer questions outside the course scope.

If the answer cannot be found in the course materials, the assistant should say that it does not have enough course evidence instead of guessing.
